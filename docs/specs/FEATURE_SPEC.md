# RoadPush 기능 명세서 (백엔드)

| 목표 | 보도 사진 한 장으로 보행자가 차도로 내려가지 않고 걸을 통로가 남아 있는지 판정하고, 검수 → 현장 조치 → 재촬영 비교까지 기록 |
|---|---|
| 사용자 | 현장 촬영자 (`/report`) · 관리자 = 지자체 · 도로관리기관 (`/dashboard`) |
| 범위 밖 | 개인 길찾기 · 휠체어 기준 판정(확장 과제) · 사고 감소 주장 |

## 기능 목록

| ID | 기능 | 핵심 규칙 | API | 화면 |
|---|---|---|---|---|
| F1 | 관측 등록 · 구간 확인 | 사진 EXIF로 시각·위치 확인 → 근처 구간 후보에서 **사용자가 확정** (거리만으로 자동 확정 안 함) → 202 즉시 접수 | `inspect` · `sites/candidates` · `POST /observations` | ✅ |
| F2 | AI 분석 | 대기열 + 워커 1개, 실행 오류 최대 3회 재시도 · RoadPush_AI 1회 호출 → 판정 · 상대 위험도 · 원인 · 근거 이미지 · **측정 불가는 유보** | (내부) | — |
| F3 | 위험 지도 | 구간별 최신 촬영 관측 · 지도 색은 사람 판정 > AI 판정 · 최신이 유보면 이전 결과로 대체하지 않음 | `GET /map` | ⬜ |
| F4 | 관측 상세 | 4.4 공통 응답 + 원본 · 근거 이미지 + 분석·검수·처리 이력 | `GET /observations/{id}` | ✅ |
| F5 | 검수 · 처리 | 확인 · 수정(오탐 사유) · 취소 / 처리 상태 · 담당 부서 / 메모 / 조치 후 관측 연결 · **AI 결과는 지우지 않음** | `reviews` · `action` · `notes` · `/actions` | ✅ (조치 연결 ⬜) |
| F6 | 전후 비교 | 같은 구간 두 관측 · 모델·규칙 버전이 같을 때만 지표 변화 계산 · 위험도 변화 ≠ 사고 감소 | `GET /sites/{id}/compare` | ⬜ |
| F7 | 검수 표 · 재분석 | 상태 · 판정 · 기간 필터 / 재분석 요청 · 시작 전 취소 (이전 결과 보존) / 잘못 올린 관측 삭제 | `GET /observations` · `reanalyze` · `DELETE` | ✅ |
| 운영 | 상태 · 문서 · 점검 | 서버·분석 엔진 상태 · Swagger UI · 모델 파일·클래스 점검 · 시연 데이터 등록 | `/health` · `/docs` · `scripts/` | — |

✅ 프론트 연결됨 · ⬜ API만 있음 (화면 연결 필요) · — 백엔드 내부

## 판정 규칙 (AI Phase 7-B 결과 → 판정)

| AI 결과 | 판정 | 위험도 |
|---|---|---|
| 걸을 면 미정 · 경계 검토 필요 · 통로 측정 불가 | 판단 유보 + 사유 → 사람 검수 | 계산 안 함 |
| 확정 + AI 판정 | AI 판정 그대로 (통과 · 좁아짐 · 단절) | 병목 비율로 계산 |
| 확정 + 상대폭만 | 남은 통로 ≥ 60% 통과 · < 30% 단절 (현장 보정 대상) | 병목 비율로 계산 |

## 상태 흐름

| 항목 | 흐름 |
|---|---|
| 처리 상태 | `pending` → `processing` → `completed`(판정 · 유보) / `failed` · 실행 오류는 `pending`으로 재시도 |
| 검수 상태 | `pending`(미검수) → `confirmed` 확인 / `corrected` 수정 → 취소하면 다시 미검수 |
| 처리 상태(조치) | 미처리 → 현장점검 요청 → 조치 중 → 조치 완료 · 변경마다 이력 |

## 비기능 요구사항

| 항목 | 기준 |
|---|---|
| 응답성 | 등록은 분석을 기다리지 않음 (202 + 대기열) · 화면은 주기적으로 다시 조회 |
| 추적성 | 분석마다 모델 · 규칙 버전 · AI 원본 응답 저장 · 재분석해도 이전 결과 · 검수 보존 |
| 보안 | Supabase 모든 테이블 RLS · 키와 DB 비밀번호는 서버 환경 변수에만 · 프론트 주소만 CORS 허용 |
| 이식성 | 배포 서버 교체 가능 · DB 스키마는 Alembic 마이그레이션으로만 변경 (서버 시작 때 자동 적용) |
| 품질 | 자동 테스트 59개 |
| 미정 | 얼굴 · 번호판 비식별 방법 · 담당자 계정·권한 |
