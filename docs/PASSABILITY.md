# 통과 여부·위험도 계산 (`app/ai_engine/passability/`)

마스터 문서 9장 팀 합의를 구현한 것입니다. 규칙 `rules-2026.10-b`, 정책 `policy-2026.10-draft`(보정 전 초안).
값이나 로직을 바꾸면 버전을 올려야 이전 분석과 비교할 수 있습니다.

## 입력: 통합 라벨 장면

노면 semantic mask(보도·차도)에 차량·비차량 instance mask를 덮어 만든 H×W 라벨 지도.

| 값 | 라벨 | 규칙에서 |
|---|---|---|
| 1 | SIDEWALK | 빈 보행면 (보도 재질 병합, 점자블록) |
| 7 | BIKE_LANE | 빈 보행면 후보. 보도 범위의 30% 넘게 섞이면 **판단 유보(mixed)**. DeepLab class1(아스팔트·우레탄 보도 + 자전거도로)은 여기로 → 정상 보행면으로 전역 확정하지 않음 |
| 4 | OBSTACLE | 장애물 **전체 실루엣 = 점유 후보** (차량 문·창문·지붕 포함) |
| 5 | TRANSIENT | 보행자. 점유가 아니라 지면을 가리는 것 |
| 0 | UNKNOWN | 가림 취급. 보도 범위의 25% 넘으면 유보 |
| 2, 3, 6 | ROAD, CURB, BACKGROUND | 보도 범위의 끝. 상시 고정시설(가로수·가로등·전봇대·볼라드·벤치)은 BACKGROUND |

보도가 화면 세로(멀어지는 방향)로 뻗는다고 보고, 주축이 가로에 가까우면 전치합니다.

## 단계

```
1. 단면(행)마다 추정 전체 보행폭 W
   빈 보행면·점유·가림이 이어진 구간 중 빈 보행면이 가장 많은 구간
   · 가려진 전체 보도는 추정 대상 → 물체 양옆과 위아래 단면의 보도 경계로 W를 잡는다
   · 폭 전체가 덮인 단면은 위아래 단면의 경계를 보간해 넣는다 (빼면 완전 차단이 분석에서 사라짐)
   · 끝이 장애물이고 그 너머가 연석·벽이 아니라 차도·화면 끝이면 "경계 애매"
     (차도 위 차량이 보도를 가린 건지, 보도에 올라온 건지 모름)

2. 가장 긴 연속 보도 구간만 분석 (3단면 이하 빈틈은 이어 붙임)

3. 품질 게이트 → 판단 유보
   보도 단면 < 30 → low_coverage · 자전거도로 > 30% → mixed · 미분류 > 25% → low_confidence

4. 단면별 남은 개별 통로 → 입구-출구 연속 통로 (max-min 경로)
   통로 값 = 통로 폭 / 그 단면의 W   (원근이 다른 단면끼리 픽셀 폭을 비교하지 않음)
   이웃 단면의 통로가 겹쳐야 이어지고, 겹친 폭도 병목 후보
   best[r,i] = max_j min(best[r-1,j], 값[r,i], 겹침[j,i])

   예) 왼쪽 40 + 상자 30 + 오른쪽 30 → 통로 40, 30 두 개. 70으로 합치지 않는다
   예) 위는 오른쪽, 아래는 왼쪽이 막혀 겹치는 통로가 없으면 → 단절

5. 낙관·보수 두 번 계산
   낙관: 보행자·미분류·경계 애매한 장애물 = 빈 땅     보수: 모두 막힘
   판정이 다르면 → 판단 유보(occluded) "가린 곳을 빈 땅으로 보면 통과, 막힘으로 보면 단절"
   같으면 → 보수 쪽 수치로 확정.  신뢰도 < 0.45 → 판단 유보(low_confidence)

6. 판정 (상대 유효폭 = 가장 좁은 단면의 남은 연속 통로 / W)
   통과 가능   ≥ 60 %
   좁아짐      30 – 60 %
   단절/우회   < 30 % 또는 입구-출구 연속 통로 없음
```

60 % · 30 %는 **보정 전 가정값**입니다. 보정용 장소 실측으로 정하고 최종 평가 전에 고정합니다.
작은 노면 오류를 morphology로 메우지 않습니다 (실제 차단까지 지워질 수 있음).

## 상대 위험도 (`risk.py`)

원 제안서 식: `R = w1 × (1 − 유효보행폭비율) + w2 × (단절길이 / 전체 분석길이)` → 0~100

- 유효보행폭비율 = 위 6의 상대 유효폭
- **단일 사진은 길이 항을 정의할 수 없어 '측정 불가'(null)** 입니다. 원근이 다른 픽셀 행 수를 길이 비율로 쓰지 않습니다.
  이때 점수는 폭 항만 반영한 **부분 상대 지표**이며 `risk_complete=false`로 표시합니다.
- 판단 유보는 점수 없음(null). 측정 불가를 0점으로 쓰지 않습니다.
- w1=0.7, w2=0.3은 초안. 여러 지점 사진·영상으로 길이 항을 정의하면 `risk_score(res, length_ratio=…)`로 반영합니다.

## 추정 절대폭 (선택)

구간에 현장 실측 보도폭(`Site.sidewalk_width_m`)이 있으면 `상대 유효폭 × 실측폭`을 `bottleneck_m_est`로 덧붙입니다.
**판정에는 쓰지 않습니다** (답변서3: 비율 중심, 절대폭·법정 기준은 초기 전제가 아님).

## 근거 (`analyses.evidence`)

- `reasons`: 화면에 그대로 보여줄 문장
- `stats`: 분석 단면 수, 미분류·자전거도로·가림·점유 비율, 경계 애매 비율, 덮인 단면 수, 낙관/보수 판정, 병목 단면, `narrow_row_fraction`(통과 기준 미만 픽셀 행 비율, 실제 길이 비율 아님)
- `risk`: 식·가중치·폭 항·길이 항·complete
- `quality`: 밝기·선명도·해상도 (저조도 + 유보면 `night`)
- 파일: `class_map.png`(통합 라벨) · `surface_overlay.jpg` · `obstacle_overlay.jpg`

## 보정 (3단계)

```bash
python scripts/analyze_folder.py data/field/calib --labels data/field/calib/labels.csv --out outputs/calib_v1
python scripts/analyze_folder.py data/field/calib --labels … --pass-ratio 0.55 --block-ratio 0.25 --out outputs/calib_v2
```
`labels.csv` 열: `file,label,sidewalk_width_m`. 현장 판정은 AI에 맞춰 고치지 않습니다.
가장 중요한 오류는 **단절·좁아짐을 통과로 놓친 것**입니다 (스크립트가 따로 셉니다).
모델이 보도를 놓치거나 물체를 못 잡은 실패는 파라미터로 숨기지 말고 모델 문제로 분리합니다.
최종 평가는 보정에 쓰지 않은 장소의 사진으로만 합니다.

## 알려진 한계

- 원근 사진의 상대폭은 "같은 단면 안 축척이 같다"는 근사입니다. 보도가 화면을 비스듬히 가로지르면 오차가 커집니다.
- 전체 실루엣을 점유로 보면 원근상 과대 차감될 수 있습니다 (`Policy.footprint_frac`로 비교 실험 가능, 기본 1.0).
- 보도가 화면 밖으로 잘리면 W를 작게 잡습니다.
- 우천 노면 반사는 자동 판별하지 않습니다.
- 휠체어·유모차 등 이용자 유형별 폭은 범위 밖입니다.
