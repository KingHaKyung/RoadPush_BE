배경 사각형이 없어서 내용만 들어갑니다. 글자는 글자 레이어, 상자·화살표·아이콘은 도형 레이어로 들어와 바로 고칠 수 있습니다.

**넣는 방법 (둘 중 하나)**
1. 파일을 Figma 캔버스로 끌어다 놓기
2. 파일을 메모장(또는 VS Code)으로 열어 전체 선택(Ctrl+A) → 복사(Ctrl+C) → Figma 캔버스에서 붙여 넣기(Ctrl+V)
   GitHub에서는 파일 화면 오른쪽 위 "Copy raw file" 버튼으로 내용을 바로 복사할 수 있습니다.

- 카드·표·판정 규칙은 이름 붙은 그룹으로 묶여 있습니다 (`1 등록`, `기능 목록`, `판정 규칙` 등). 따로 쓰려면 그룹 해제(Ctrl+Shift+G)
- 글꼴: Noto Sans KR · JetBrains Mono (Figma 기본 제공 Google Fonts)
